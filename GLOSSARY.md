# FractalSync — Context

FractalSync is a live music visualizer that renders morphing Julia sets driven by a learned model ("the Player") listening to music in real time. The experience is a "sober acid trip" amplifying song emotion for a Tool tribute band's live show.

## Glossary (from docs/DOMAIN_CONTRACT.md)

- **The Map** — Mandelbrot set, atlas of every possible Julia set
- **c** — current position on the Map; selects the Julia set on screen
- **Inside / Outside** — c within / beyond the Map (connected vs dust Julia set)
- **The Shore** — edge of the Map; richest visual structure
- **Energy / Brightness** — loudness / high-frequency character of the music
- **Momentum / Acceleration / Jitter** — c's velocity state driven by Energy
- **Player / Controls / Physics / Hands off** — learned controller vs world defaults

See `docs/DOMAIN_CONTRACT.md` for the full domain contract (obligations, world facts, design discipline).

## Key technical contracts

### Rust-first parity (ADR 0001)
`runtime-core` is the single source of truth for all runtime-consumed math: orbit synthesis, geometry, feature extraction, minimap, and visual metrics. Mirrors (`backend/src/cspace_proxies.py`, `backend/src/python_feature_extractor.py`, `frontend/src/lib/canonicalFeatures.ts` via `wasm-orbit`) must stay in behavioral parity, verified by `shared/golden_vectors.json` and `scripts/preflight_parity.py` (wired into `backend/train.py`). See `docs/adr/0001-rust-first-parity.md`.

### Versions
- `FEATURE_VERSION` (`runtime-core/src/features.rs`): current `features/2`. History: `features/1` causal baseline (fixed transforms, frame-major), `features/2` flux-mean fix. Bumped with `shared/golden_vectors.json` regeneration in the same commit; browser and trainer refuse mismatched `feature_version` in ONNX metadata.
- `CONTROLLER_VERSION` (`runtime-core/src/controller.rs`): current `orbit-controller/1`. Bumped with goldens/mirrors in the same commit when `OrbitController::step` semantics change; same refusal/stale-golden guards as above.

### Training ↔ browser contract
Training exports ONNX (`opset 18`) + `*_metadata.json` with `input_shape`, `output_dim`, `parameter_names`, `parameter_ranges`, `feature_mean`/`feature_std`, `model_type: orbit_control`, `k_bands`, `feature_version`, `controller_version`. The browser (`frontend/src/lib/modelInference.ts`) loads them and refuses mismatched versions.

## Repository layout
- `runtime-core/` — canonical Rust runtime

- `shared/golden_vectors.json` — parity oracle generated by `runtime-core/src/bin/generate_golden_vectors.rs`
